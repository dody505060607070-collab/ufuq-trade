# خطة التطوير الكبرى: العقل الذكي + الربط متعدد المنصات + رادار الحيتان

ملحوظة: مفيش أي خطأ في الموقع. الملف المرفوع فيه طلب تنفيذ الخطط اللي اتفقنا عليها.

## الشكل العام (لكل الصفحات الجديدة)
- نفس الثيم الداكن واللون البنفسجي وخط Geist.
- كروت زجاجية بحدود خفيفة، أرقام كبيرة واضحة، ألوان أخضر للربح وأحمر للخسارة.
- كل النصوص بالعربي والإنجليزي، ومناسبة للموبايل.
- قائمة جانبية فيها 3 صفحات جديدة: «العقل الذكي»، «المنصات المتصلة»، «رادار الحيتان».

## الخطة 1: العقل الذكي وسجل التعلم (بديل Obsidian داخل الموقع)
1. كل صفقة تتقفل، الذكاء الاصطناعي يكتب عنها تقرير قصير: ليه دخلت، ليه كسبت أو خسرت، والدرس المستفاد.
2. بنك قواعد متعلمة: الدروس المتكررة تتحول لقواعد (مثال: «تجنب البيع على الذهب قبل الأخبار الأمريكية»)، وتقدر تفعل أو توقف أي قاعدة.
3. القواعد النشطة تدخل في كل تحليل جديد، فالنظام يتحسن مع الوقت.
4. صفحة «العقل الذكي»:
   - بطاقات: عدد الدروس، نسبة النجاح، أقوى وأضعف وقت تداول.
   - خط زمني لتقارير الصفقات مع بحث وفلترة (ربح/خسارة/أداة).
   - شبكة مرئية تربط الصفقات بالقواعد اللي اتعلمت منها.
   - ملخص أسبوعي تلقائي: «إيه اللي اتعلمه النظام الأسبوع ده».
5. للتوفير: التقرير يتعمل مرة واحدة لكل صفقة، والملخص مرة في الأسبوع.

## الخطة 2: الربط متعدد المنصات (فكرة Liquid.Trade)
1. MetaTrader 5 يفضل زي ما هو بالظبط.
2. صفحة «المنصات المتصلة» بشكل كروت: MT5، TradeLocker، Hyperliquid (كريبتو 24/7).
3. كل منصة لها حالة اتصال، رصيد، صفقات مفتوحة، وزرار تشغيل/إيقاف الأتمتة.
4. نفس عقل الذكاء الاصطناعي ونفس قواعد الأمان وحجز الربح تشتغل على كل المنصات.
5. البداية: نجهز الشكل والأساس، وHyperliquid يشتغل على حساب تجريبي (Testnet) الأول. TradeLocker يحتاج بيانات API منك وقت التنفيذ.

## الخطة 3: رادار الحيتان (فكرة Quiver Quant)
1. صفحة «رادار الحيتان»: صفقات أعضاء الكونجرس، مشتريات المطلعين داخل الشركات، وتدفقات صناديق الذهب.
2. مؤشر «مزاج الأموال الكبيرة» (صاعد/هابط/محايد) لكل أداة.
3. المؤشر يدخل في تحليل الذكاء الاصطناعي كخبير سابع.
4. بيانات Quiver Quant مدفوعة (اشتراك شهري)، فهنبدأ بمصادر مجانية (تقارير الإفصاح العامة وتقارير COT الأسبوعية للذهب)، وتقدر تضيف مفتاح Quiver لاحقًا.

## ترتيب التنفيذ
1. العقل الذكي (أكبر أثر على جودة التداول).
2. رادار الحيتان (مصادر مجانية).
3. المنصات المتصلة.

## تنبيه
مفيش نظام يضمن الربح؛ الهدف تحسين القرارات وحماية رأس المال، والتجربة على Demo أولًا.

## تفاصيل تقنية
- جداول جديدة: trade_lessons، learned_rules، weekly_reviews، broker_connections، whale_signals، كلها بصلاحيات على مستوى المستخدم.
- التقرير يتولد داخل /api/public/ea/sync عند تغيّر الصفقة لـ closed (Gemini، مرة واحدة لكل trade_id).
- القواعد النشطة تتضاف لبرومبت runAI جنب Trade memory.
- ملخص أسبوعي ورادار الحيتان: جدولة يومية/أسبوعية عبر server routes تحت /api/public/ محمية بـ cron secret.
- Hyperliquid عبر REST مع مفتاح محفوظ في السيرفر فقط، تنفيذ open/close من نفس طابور trade_commands.
- مصادر مجانية: SEC/House disclosures وCFTC COT؛ Quiver اختياري بمفتاح QUIVER_API_KEY.
